# Dragon

Dragon boss, arena, attack-pose, and flying-animation artwork lives in this folder.

Current gameplay-ready artwork:

- `dragon-arena.png` — 2560×1440 top-down boss arena
- `dragon-boss-flap-up.png` — wing upstroke
- `dragon-boss-flap-upper-middle.png` — transition out of the upstroke
- `dragon-boss-flap-middle.png` — middle/extended wing position
- `dragon-boss-flap-lower-middle.png` — transition into the downstroke
- `dragon-boss-flap-down.png` — wing downstroke
- `dragon-boss-fire-attack.png` — fire-breath attack pose
- `dragon-rider-freeze-attack.png` — rider's spectral ice-dragon projectile

Cycle the flying frames in this order for a seamless flap:
`up → upper-middle → middle → lower-middle → down → lower-middle → middle → upper-middle`.
