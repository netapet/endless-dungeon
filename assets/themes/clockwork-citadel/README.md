# Clockwork Citadel

Dedicated assets for the Clockwork Archon encounter.

- `clockwork-archon.png` — Clockwork Archon boss sprite (boss 23)
- `clockwork-orb.png` — summoned Clockwork Orb minion
- `clock-arena.png` — Clockwork Citadel boss arena

The game uses the internal IDs `clockworkArchon` and `clockworkOrb`. The older
Clockwork Seraph is a separate design and is not used by this encounter.
