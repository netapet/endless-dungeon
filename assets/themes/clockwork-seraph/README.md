# Clockwork Seraph

This folder is the self-contained asset section for **Aurelius, the Clockwork Seraph** (boss 28). It is separate from the Clockwork Archon and Clockwork Citadel assets.

## Game assets

- `clockwork-seraph.png` — playable boss sprite
- `clockwork-arena.png` — Celestial Clockworks boss arena
- `seraph-halberd-sweep-separated.png` — 3-frame chrono-halberd attack strip
- `seraph-portal-lance-separated.png` — 3-frame portal-lance attack strip
- `seraph-feather-barrage-separated.png` — 4-frame feather-barrage attack strip
- `seraph-clockfall-separated.png` — 4-frame Clockfall ultimate strip

The original montage and source images remain in this folder for future edits. Each separated strip is rendered at high resolution and the game preserves its native aspect ratio.

Open [ATTACKS.md](ATTACKS.md) for a visual list of every attack currently wired into the game.
