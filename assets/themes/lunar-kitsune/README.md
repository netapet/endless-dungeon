# Lunar Kitsune

Moonlit boss artwork and separated transparent attack sequences.

- `lunar-kitsune.png` — boss sprite
- `lunar-arena.png` — boss arena
- `lunar-crescent-cut-separated.png` — crescent melee sequence
- `lunar-orb-cast-separated.png` — lunar-orb casting sequence
- `lunar-foxfire-rush-separated.png` — spectral fox rush sequence
- `lunar-moonfall-separated.png` — meteor and eclipse-eruption sequence

Each `*-separated.png` file is an attack-classified animation strip with real
alpha transparency rather than a rectangular crop from the source montage.
