# Dark Magic Sovereign

Dedicated assets for the tier-29 Dark Magic Sovereign encounter.

- `dark-magic-sovereign.png` — high-resolution transparent boss sprite
- `dark-magic-arena.png` — high-resolution top-down Umbral Crucible arena

The encounter uses four attacks: Void Claw, Umbral Rift Dash, Dark Lance Volley,
and the large-area Eclipse Nova.
