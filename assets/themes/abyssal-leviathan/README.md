# Abyssal Leviathan

Dedicated artwork for the octopus encounter.

- `octopus-boss.png` — Abyssal Leviathan boss sprite
- `octopus-minion.png` — Abyssal Tentacle minion sprite
- `octopus-arena.png` — encounter arena
- `octopus-attacks.png` — attack animation and effect montage

The encounter is playable as boss tier 27 and in the Pantheon. It includes
Tentacle Slam, Constriction Vortex, Ink Cloud, and summoned Abyssal Tentacles.
